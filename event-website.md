## 🏗️ Technology Architecture

### 🔹 Frontend

* React / Next.js (fast, SEO-friendly, scalable UI)
* Tailwind CSS (modern, responsive design)
* Progressive Web App (PWA) support

### 🔹 Backend

* Node.js + Express (high-performance APIs)

### 🔹 Database Strategy (Hybrid Approach)

| Use Case                         | Technology |
| -------------------------------- | ---------- |
| Event listings, dynamic content  | MongoDB    |
| Payments, bookings, transactions | PostgreSQL |

👉 This ensures **flexibility + strict data integrity where required**

## ☁️ Cloud Infrastructure (AWS)

### Core Components

* **EC2** → Backend services
* **RDS (PostgreSQL)** → Transactional data
* **MongoDB Atlas** → Event data
* **S3 + CloudFront** → Media & CDN
* **Lambda** → Background jobs
* **API Gateway** → Secure API routing

### High Availability

* Multi-zone deployment
* Auto-scaling infrastructure
* Failover-ready databases
