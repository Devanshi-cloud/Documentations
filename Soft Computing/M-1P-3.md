# 1. Defuzzification

## What is Defuzzification?
I use **defuzzification** when I need to convert:

```text
Fuzzy Output → Crisp Output
```

Example:

Temperature = {(20,0.4), (30,0.7), (40,1)}

Need one crisp answer:
**35°C**

### Why?
Because machines need exact decisions.

Example:
If temperature is high → rotate fan at **speed 4**
(not “somewhat fast”)

---

## Defuzzification Methods
1. Lambda-cut
2. Maxima methods
3. Centroid methods
4. Weighted Average

---

# 2. Lambda-Cut Method

Also called:
**Alpha-cut**

Formula:

\[
A_\lambda = \{x \mid \mu_A(x)\geq \lambda \}
\]

Meaning:
Keep only values whose membership is ≥ λ

---

### Example

A={(x1,0.9),(x2,0.5),(x3,0.2)}

If λ = 0.6

Answer:

{x1}

because only 0.9 ≥ 0.6

---

## Properties

\[
(A \cup B)_\lambda = A_\lambda \cup B_\lambda
\]

\[
(A \cap B)_\lambda = A_\lambda \cap B_\lambda
\]

Memory:
- Union stays union
- Intersection stays intersection

---

# 3. Maxima Methods

Use when I want crisp value from **maximum membership**.

---

## (a) Height Method

Rule:
Pick value having highest membership.

Works only if maximum is unique.

Example:

(45,1)

Answer:
45

---

## (b) First of Maxima (FoM)

Take first maximum.

Example:

(45,1), (50,1)

Answer:
45

---

## (c) Last of Maxima (LoM)

Take last maximum.

Answer:
50

---

## (d) Mean of Maxima (MoM)

Take average.

\[
(45+50)/2 = 47.5
\]

Answer:
47.5

---

### Memory Trick

FoM = First  
LoM = Last  
MoM = Mean

---

# 4. Centroid Methods

Most important method.

Idea:
Find **center of balance**.

Like balancing cardboard.

---

## (a) Center of Gravity (CoG)

Formula:

\[
x^*=\frac{\sum x\mu(x)}{\sum \mu(x)}
\]

Steps:
1. Multiply x × membership
2. Add all
3. Divide by total membership

---

### Example

(10,0.2), (20,0.5)

Numerator:

10×0.2 + 20×0.5 = 12

Denominator:

0.7

Answer:

12/0.7 = 17.14

---

### Note
Overlapping counted **once**

---

## (b) Center of Sum (CoS)

Formula:

\[
x^*=\frac{\sum C_iA_i}{\sum A_i}
\]

Where:
- Ci = centroid
- Ai = area

Important:
Overlapping counted **multiple times**

---

### Difference

| CoG | CoS |
|-----|-----|
| overlap once | overlap multiple times |

---

## (c) Center of Area (CoA)

Choose region with **largest area**,
then take its centroid.

---

# 5. Weighted Average Method

Formula:

\[
x^*=\frac{\sum x_iw_i}{\sum w_i}
\]

Simple weighted mean.

Used heavily in **Sugeno**.

---

# 6. Fuzzy Logic Controller (FLC)

Used when exact math is difficult.

Examples:
- AC
- Washing machine
- ABS
- Robotics

---

## Architecture

```text
Input
 ↓
Fuzzification
 ↓
Rule Base
 ↓
Inference Engine
 ↓
Defuzzification
 ↓
Output
```

---

## Step 1: Fuzzification

Convert crisp → fuzzy

Example:

30°C → medium(0.7), high(0.3)

---

## Step 2: Rule Base

Example:

If temperature high → fan high

Knowledge lives here.

---

## Step 3: Inference Engine

Applies rules.

Common:
- Min-Max
- Mamdani

---

## Step 4: Defuzzification

Convert fuzzy → crisp

Example:
fan speed = 3.4

---

# Types of FLC

## Mamdani
- Output is fuzzy
- Needs defuzzification
- Human friendly

---

## Sugeno
Output is equation:

\[
z=ax+by+c
\]

Fast and efficient.

Used in optimization.

---

# Mamdani AC Example

Inputs:
- Temperature
- Humidity

Output:
- Fan Speed

Rules:
If temp high and humidity high → fan high

Inference:

Low = 0.2  
Medium = 0.5  
High = 0.3

Weighted average:

\[
=(1×0.2)+(3×0.5)+(6×0.3)=3.5
\]

Meaning:
Medium speed

# 7. Fuzzy Relations

Relation = mapping between sets.

---

## Crisp Relation

X={1,2}

Y={3,4}

\[
X \times Y=
\{(1,3),(1,4),(2,3),(2,4)\}
\]

---

## Fuzzy Relation

Each pair has degree.

Example:

((1,3),0.7)

Meaning:
relation strength = 0.7

---

## Operations

### Union

\[
\mu_{R\cup S}=max(\mu_R,\mu_S)
\]

### Intersection

\[
\mu_{R\cap S}=min(\mu_R,\mu_S)
\]

### Complement

\[
\bar R = 1-\mu_R
\]

---

## Composition

Most important:

\[
T(x,z)=max[min(R(x,y),S(y,z))]
\]

Always:
**first min, then max**

---

# 8. Fuzzy Propositions

Crisp:
True or False

Fuzzy:
Truth between 0 and 1

Example:
“Ram is honest”

0 → false  
0.5 → maybe  
1 → true

---

## Operations

NOT:

\[
1-T(P)
\]

OR:

\[
max(T(P),T(Q))
\]

AND:

\[
min(T(P),T(Q))
\]

Implication:

\[
max(1-T(P),T(Q))
\]

---

# 9. Fuzzy Implication

General rule:

```text
If x is A then y is B
```

Symbol:

\[
A \rightarrow B
\]

---

## Interpretation 1: A coupled with B

Build relation:

\[
R=A\times B
\]

Methods:

### Mamdani
\[
min(a,b)
\]

### Larsen
\[
ab
\]

### Bounded
\[
max(0,a+b-1)
\]

### Drastic
Special case

---

## Interpretation 2: A entails B

Logical implication.

Material implication:

\[
R=\bar A \cup B
\]

Formula:

\[
max(1-a,b)
\]

---

## Zadeh Rule

\[
max(1-a,min(a,b))
\]

Important.

---

## Goguen Rule

If:

a ≤ b → 1

Else:

\[
b/a
\]

---

### Memory
Coupled = connection

Entails = logic

# 10. Fuzzy Inferring Procedures

Two methods:
1. GMP
2. GMT

---

## Generalized Modus Ponens (GMP)

Forward reasoning.

Rule:

If x is A then y is B

Given:

x is A'

Find:

y is B'

Formula:

\[
B' = A' \circ R(x,y)
\]

Expanded:

\[
\mu_{B'}(y)=max[min(\mu_{A'}(x),\mu_R(x,y))]
\]

Meaning:
input known → output find

---

### Example

A={(x1,0.5),(x2,1),(x3,0.6)}

B={(y1,1),(y2,0.4)}

A'={(x1,0.6),(x2,0.9),(x3,0.7)}

Result:

B'={(y1,0.9),(y2,0.5)}

---

## Generalized Modus Tollens (GMT)

Backward reasoning.

Rule:

If x is A then y is B

Given:

y is B'

Find:

x is A'

Formula:

\[
A' = B' \circ R(x,y)
\]

Expanded:

\[
\mu_{A'}(x)=max[min(\mu_{B'}(y),\mu_R(x,y))]
\]

Meaning:
output known → input find

---

# GMP vs GMT

| GMP | GMT |
|-----|-----|
| forward | backward |
| input known | output known |
| find output | find input |

Memory:

Ponens = Push forward

Tollens = Trace backward
