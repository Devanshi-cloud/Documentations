# Fuzzy Logic Controller (FLC)

## What is FLC?

I know:

**FLC = smart controller that makes decisions like a human using fuzzy rules.**

Instead of exact math, it thinks like:
- low
- medium
- high

Then gives exact output.

Example:
Temperature high → Fan fast

---

# Why do I use FLC?

I use it when exact mathematical model is difficult.

Examples:
- nonlinear systems
- uncertain systems
- changing environment

Shortcut:
**When math fails, fuzzy helps.**

---

# Structure of FLC

```text
Crisp Input
   ↓
Fuzzification
   ↓
Rule Base + Inference Engine
   ↓
Defuzzification
   ↓
Crisp Output
```

Memory:
**F → R → I → D**
(Fuzzify → Rule → Infer → Defuzzify)

---

# Step 1: Fuzzification

Convert number → fuzzy word

Example:
32°C becomes:
- Low = 0.1
- Medium = 0.4
- High = 0.8

Now machine understands.

---

# Step 2: Rule Base

Store expert rules.

Example:

IF temperature is High
THEN fan speed is Fast

These are human-like rules.

---

# Step 3: Inference Engine

Apply rules.

Example:
High = 0.8
→ rule fires with strength 0.8

Common methods:
- Min-Max
- Mamdani

---

# Step 4: Defuzzification

Convert fuzzy output → exact number

Example:
Fast → 85 RPM

Done.

---

# Mamdani Approach: Automatic AC Control

Goal:

Input:
- Temperature
- Humidity

Output:
- Fan Speed

Simple:

Temp + Humidity → Fan Speed

---

# Step 1: Define Fuzzy Sets

## Temperature
- Low → 15–22
- Medium → 22–30
- High → 30–40

---

## Humidity
- Low → 30–50
- Medium → 50–70
- High → 70–90

---

## Fan Speed
- Low → 0–3
- Medium → 3–6
- High → 6–10

---

# Step 2: Fuzzification

Suppose:

Temperature = 32°C
Humidity = 65%

Convert:

Temperature:
- Medium = 0.4
- High = 0.6

Humidity:
- Medium = 0.7
- High = 0.3

Now fuzzy input ready.

---

# Step 3: Rule Base

Examples:

1. IF Temp Low AND Humidity Low → Fan High
2. IF Temp Medium AND Humidity Medium → Fan Medium
3. IF Temp High AND Humidity Low → Fan High
4. IF Temp High AND Humidity High → Fan Medium

These are expert rules.

---

# Step 4: Mamdani Inference

Uses:

AND → Min
Combine → Max

Example:

Temp High = 0.6
Humidity Medium = 0.7

Rule:
IF Temp High AND Humidity Medium → Fan High

Activation:
min(0.6,0.7)=0.6

Rule fires with 0.6

---

# Step 5: Aggregate Output

Suppose final fuzzy output:

Low = 0.2
Medium = 0.5
High = 0.3

Still fuzzy.

---

# Step 6: Defuzzification

Use weighted average:

x* = Σ(xμ)/Σμ

Take:
Low = 1
Medium = 3
High = 6

Calculation:

= (1×0.2 + 3×0.5 + 6×0.3)/(0.2+0.5+0.3)

= 0.2 + 1.5 + 1.8

= 3.5

Final output:
**Fan speed = Medium**

---

# Full Mamdani Flow

```text
Temperature + Humidity
        ↓

Min-Max Inference
        ↓
Aggregate
        ↓
Defuzzification
        ↓
Final Fan Speed
```
