
# Q1: Why HR is important—but not for business plans

In my startup, I realized early that **my first hires define my future**.

So I used HR for:

* finding missing talent gaps,
* attracting strong people,
* designing salary + ESOP packages,
* avoiding legal mistakes in hiring/firing.

But **business planning for investors? That’s my job as founder.**
I own the vision, market story, and numbers.

So option **(c)** is wrong.

**My thinking:**
“HR helps me build the team; it doesn’t build my startup thesis.”

# Q8: Shareholding calculation

My company:

* A = 20 shares
* B = 10 shares
* C = 20 shares

Total = **50 shares**

So:

* A = 20/50 = **40%**
* B = 10/50 = **20%**
* C = 20/50 = **40%**

Answer: **(d)**

Simple rule:

[
\text{Ownership} = \frac{\text{Your shares}}{\text{Total shares}}
]

\text{Ownership}=\frac{\text{Your shares}}{\text{Total shares}}

# Q9: Angel invests ₹10,000

Before funding:

* founders own 50 shares.

Investor wants **50%**.

That means after funding total shares must become:

[
50 \times 2 = 100
]

Need new shares:

[
100 - 50 = 50
]

So I issue **50 new shares**.

Answer: **(b)**

**Why new shares?**
Because money must go **into company**, not into founders’ pockets.

That’s dilution.

# Q10: Angel invests ₹40M at ₹120M pre-money

My formula:

[
Post = Pre + Investment
]

[
160 = 120 + 40
]

Investor ownership:

[
40/160 = 25%
]

\frac{40}{160}=25%

Founders keep **75%**.

Current founder shares = 750.

Let total future shares = X

[
750 = 75% \text{ of } X
]

[
X = 1000
]

Angel gets:

[
1000 - 750 = 250
]

Answer: **(a)**

**My founder logic:**
“I don’t give away existing shares. I create new ones and dilute proportionally.”
